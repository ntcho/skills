# POST /campaigns/{campaign_id}/actions/test

**Resource:** [campaigns](../resources/campaigns.md)
**Send test email**
**Operation ID:** `postCampaignsIdActionsTest`

Send a test email.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `campaign_id` | path | string | Yes | The unique id for the campaign. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `test_emails` | string[] | Yes | An array of email addresses to send the test email to. |
| `send_type` | enum: html, plaintext | Yes | Choose the type of test email to send. |

## Responses

| Status | Description |
|--------|-------------|
| 204 | Empty Response |
| default | An error generated by the Mailchimp API. |
