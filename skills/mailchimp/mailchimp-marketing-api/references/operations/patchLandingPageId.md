# PATCH /landing-pages/{page_id}

**Resource:** [landingPages](../resources/landingPages.md)
**Update landing page**
**Operation ID:** `patchLandingPageId`

Update a landing page.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `page_id` | path | string | Yes | The unique id for the page. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | No | The name of this landing page. |
| `title` | string | No | The title of this landing page seen in the browser's title bar. |
| `description` | string | No | The description of this landing page. |
| `store_id` | string | No | The ID of the store associated with this landing page. |
| `list_id` | string | No | The list's ID associated with this landing page. |
| `tracking` | object | No | The tracking settings applied to this landing page. |

**`tracking` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `track_with_mailchimp` | boolean | No | Use cookies to track unique visitors and calculate overall conversion rate. Learn more [here](https://mailchimp.com/help/use-track-mailchimp/). |

You can learn more about Google's restricted data processing within Google Ads [here](https://privacy.google.com/businesses/rdp/). |
