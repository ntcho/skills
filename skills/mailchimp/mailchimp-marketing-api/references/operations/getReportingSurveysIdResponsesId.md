# GET /reporting/surveys/{survey_id}/responses/{response_id}

**Resource:** [reporting](../resources/reporting.md)
**Get survey response**
**Operation ID:** `getReportingSurveysIdResponsesId`

Get a single survey response.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `survey_id` | path | string | Yes | The ID of the survey. |
| `response_id` | path | string | Yes | The ID of the survey response. |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Get a single survey response. |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `response_id` | string | No | The ID for the survey response. |
| `submitted_at` | string (date-time) | No | The date and time when the survey response was submitted in ISO 8601 format. |
| `contact` | object | No | Information about the contact. |
| `is_new_contact` | boolean | No | If this contact was added to the Mailchimp audience via this survey. |
| `results` | object[] | No | The survey questions and the answers to those questions. |

**`contact` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email_id` | string | No | The MD5 hash of the lowercase version of the list member's email address. |
| `contact_id` | string | No | The ID of this contact. |
| `status` | enum: Subscribed, Unsubscribed, Non-Subscribed... | No | The contact's current status. |
| `email` | string | No | The contact's email address. |
| `phone` | string | No | The contact's sms phone number. |
| `full_name` | string | No | The contact's full name. |
| `consents_to_one_to_one_messaging` | boolean | No | Indicates whether a contact consents to 1:1 messaging. |
| `avatar_url` | string | No | URL for the contact's avatar or profile image. |

**`results` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `question_id` | string | No | The unique ID for this question. |
| `question_type` | enum: pickOne, pickMany, range... | No | The type of question this is. |
| `query` | string | No | The survey question. |
| `answer` | string | No | The answer to this survey question. |
