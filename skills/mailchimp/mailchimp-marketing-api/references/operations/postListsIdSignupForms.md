# POST /lists/{list_id}/signup-forms

**Resource:** [lists](../resources/lists.md)
**Customize signup form**
**Operation ID:** `postListsIdSignupForms`

Customize a list's default signup form.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `header` | object | No | Options for customizing your signup form header. |
| `contents` | object[] | No | The signup form body content. |
| `styles` | object[] | No | An array of objects, each representing an element style for the signup form. |

**`header` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `image_url` | string | No | Header image URL. |
| `text` | string | No | Header text. |
| `image_width` | string | No | Image width, in pixels. |
| `image_height` | string | No | Image height, in pixels. |
| `image_alt` | string | No | Alt text for the image. |
| `image_link` | string | No | The URL that the header image will link to. |
| `image_align` | enum: none, left, center... | No | Image alignment. |
| `image_border_width` | string | No | Image border width. |
| `image_border_style` | enum: none, solid, dotted... | No | Image border style. |
| `image_border_color` | string | No | Image border color. |
| `image_target` | enum: _blank, null | No | Image link target. |

**`contents` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `section` | enum: signup_message, unsub_message, signup_thank_you_title | No | The content section name. |
| `value` | string | No | The content section text. |

**`styles` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `selector` | enum: page_background, page_header, page_outer_wrapper... | No | A string that identifies the element selector. |
| `options` | object[] | No | A collection of options for a selector. |
