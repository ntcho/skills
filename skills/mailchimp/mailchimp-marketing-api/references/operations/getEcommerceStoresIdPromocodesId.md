# GET /ecommerce/stores/{store_id}/promo-rules/{promo_rule_id}/promo-codes/{promo_code_id}

**Resource:** [ecommerce](../resources/ecommerce.md)
**Get promo code**
**Operation ID:** `getEcommerceStoresIdPromocodesId`

Get information about a specific promo code.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `store_id` | path | string | Yes | The store id. |
| `promo_rule_id` | path | string | Yes | The id for the promo rule of a store. |
| `promo_code_id` | path | string | Yes | The id for the promo code of a store. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |
