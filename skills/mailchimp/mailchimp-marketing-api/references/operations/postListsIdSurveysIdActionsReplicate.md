# POST /lists/{list_id}/surveys/{survey_id}/actions/replicate

**Resource:** [lists](../resources/lists.md)
**Replicate survey**
**Operation ID:** `postListsIdSurveysIdActionsReplicate`

Replicate a survey.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |
| `survey_id` | path | string | Yes | The ID of the survey. |

## Request Body

Survey replicate request.

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | No | The title for the replicated survey. |
| `list_id` | string | No | The unique ID of the audience for the replicated survey. Defaults to the source survey audience. |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Survey replicated. |
| default | An error generated by the Mailchimp API. |
