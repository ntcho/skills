# POST /ecommerce/stores/{store_id}/orders/{order_id}/lines

**Resource:** [ecommerce](../resources/ecommerce.md)
**Add order line item**
**Operation ID:** `postEcommerceStoresIdOrdersIdLines`

Add a new line item to an existing order.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `store_id` | path | string | Yes | The store id. |
| `order_id` | path | string | Yes | The id for the order in a store. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | A unique identifier for the order line item. |
| `product_id` | string | Yes | A unique identifier for the product associated with the order line item. |
| `product_variant_id` | string | Yes | A unique identifier for the product variant associated with the order line item. |
| `product` | object | No | Information about a specific product. |
| `quantity` | integer | Yes | The quantity of an order line item. |
| `price` | number | Yes | The price of an order line item. |
| `discount` | number | No | The total discount amount applied to this line item. |

**`product` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | A unique identifier for the product. |
| `title` | string | Yes | The title of a product. |
| `handle` | string | No | The handle of a product. |
| `url` | string | No | The URL for a product. |
| `description` | string | No | The description of a product. |
| `type` | string | No | The type of product. |
| `vendor` | string | No | The vendor for a product. |
| `image_url` | string | No | The image URL for a product. |
| `variants` | object[] | Yes | An array of the product's variants. At least one variant is required for each product. A variant can use the same `id` and `title` as the parent product. |
| `images` | object[] | No | An array of the product's images. |
| `published_at_foreign` | string (date-time) | No | The date and time the product was published. |
