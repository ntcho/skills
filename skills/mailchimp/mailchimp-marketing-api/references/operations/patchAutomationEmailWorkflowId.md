# PATCH /automations/{workflow_id}/emails/{workflow_email_id}

**Resource:** [automations](../resources/automations.md)
**Update workflow email**
**Operation ID:** `patchAutomationEmailWorkflowId`

Update settings for a classic automation workflow email.  Only works with workflows of type: abandonedBrowse, abandonedCart, emailFollowup, or singleWelcome.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `workflow_id` | path | string | Yes | The unique id for the Automation workflow. |
| `workflow_email_id` | path | string | Yes | The unique id for the Automation workflow email. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `settings` | object | No | Settings for the campaign including the email subject, from name, and from email address. |
| `delay` | object | No | The delay settings for an automation email. |

**`settings` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `subject_line` | string | No | The subject line for the campaign. |
| `preview_text` | string | No | The preview text for the campaign. |
| `title` | string | No | The title of the Automation. |
| `from_name` | string | No | The 'from' name for the Automation (not an email address). |
| `reply_to` | string | No | The reply-to email address for the Automation. |

**`delay` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `amount` | integer | No | The delay amount for an automation email. |
| `type` | enum: now, day, hour... | No | The type of delay for an automation email. |
| `direction` | enum: after | No | Whether the delay settings describe before or after the delay action of an automation email. |
| `action` | enum: signup, ecomm_abandoned_browse, ecomm_abandoned_cart | Yes | The action that triggers the delay of an automation emails. |
