# GET /authorized-apps/{app_id}

**Resource:** [authorizedApps](../resources/authorizedApps.md)
**Get authorized app info**
**Operation ID:** `getAuthorizedAppsId`

Get information about a specific authorized application.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `app_id` | path | string | Yes | The unique id for the connected authorized application. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | integer | No | The ID for the application. |
| `name` | string | No | The name of the application. |
| `description` | string | No | A short description of the application. |
| `users` | string[] | No | An array of usernames for users who have linked the app. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
