# GET /reporting/landing-pages/{outreach_id}

**Resource:** [reporting](../resources/reporting.md)
**Get landing page report**
**Operation ID:** `getReportingLandingPagesId`

Get report of a landing page.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `outreach_id` | path | string | Yes | The outreach id. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Landing Page Report Instance |
| default | An error generated by the Mailchimp API. |

| `url` | string | No | The landing page url. |

| `unpublished_at` | string (date-time) | No | The time this landing page was unpublished. |

| `list_id` | string | No | The list id connected to this landing page. |
| `visits` | integer | No | The number of visits to this landing pages. |

| `conversion_rate` | number | No | The percentage of people who visited your landing page and were added to your list. |
| `timeseries` | object | No |  |
