# GET /audiences/{audience_id}

**Resource:** [contacts](../resources/contacts.md)
**Get audience info**
**Operation ID:** `getAudienceId`

Get information about a specific audience.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `audience_id` | path | string | Yes | The unique ID for the audience. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | The unique ID for the audience. |
| `name` | string | No | The name of an audience |
| `stats` | object | No |  |
| `enabled_channels` | string[] | No | The communication channels enabled on an audience |

**`stats` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `total_contacts` | integer | No | The total count of all contacts in an audience |
