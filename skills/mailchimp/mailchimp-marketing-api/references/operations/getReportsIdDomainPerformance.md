# GET /reports/{campaign_id}/domain-performance

**Resource:** [reports](../resources/reports.md)
**List domain performance stats**
**Operation ID:** `getReportsIdDomainPerformance`

Get statistics for the top-performing email domains in a campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `campaign_id` | path | string | Yes | The unique id for the campaign. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `domains` | object[] | No | The top 5 email domains based on total delivered emails. |
| `total_sent` | integer | No | The total number of emails sent for the campaign. |
| `campaign_id` | string | No | The unique id for the campaign. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`domains` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `domain` | string | No | The name of the domain (gmail.com, hotmail.com, yahoo.com). |
| `emails_sent` | integer | No | The number of emails sent to that specific domain. |
| `bounces` | integer | No | The number of bounces at a domain. |
| `opens` | integer | No | The number of opens for a domain. |
| `clicks` | integer | No | The number of clicks for a domain. |
| `unsubs` | integer | No | The total number of unsubscribes for a domain. |
| `delivered` | integer | No | The number of successful deliveries for a domain. |
| `emails_pct` | number | No | The percentage of total emails that went to this domain. |
| `bounces_pct` | number | No | The percentage of total bounces from this domain. |
| `opens_pct` | number | No | The percentage of total opens from this domain. |
| `clicks_pct` | number | No | The percentage of total clicks from this domain. |
| `unsubs_pct` | number | No | The percentage of total unsubscribes from this domain. |
