# GET /reports/{campaign_id}/eepurl

**Resource:** [reports](../resources/reports.md)
**List EepURL activity**
**Operation ID:** `getReportsIdEepurl`

Get a summary of social activity for the campaign, tracked by EepURL.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `campaign_id` | path | string | Yes | The unique id for the campaign. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `twitter` | object | No | A summary of Twitter activity for a campaign. |
| `clicks` | object | No | A summary of the click-throughs on the campaign's URL. |
| `referrers` | object[] | No | A summary of the top referrers for the campaign. |
| `eepurl` | string | No | The shortened link used for tracking. |
| `campaign_id` | string | No | The unique id for the campaign. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`twitter` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `tweets` | integer | No | The number of tweets including a link to the campaign. |
| `first_tweet` | string | No | The day and time of the first recorded tweet with a link to the campaign. |
| `last_tweet` | string | No | The day and time of the last recorded tweet with a link to the campaign. |
| `retweets` | integer | No | The number of retweets that include a link to the campaign. |
| `statuses` | object[] | No | A summary of tweets that include a link to the campaign. |

**`clicks` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `clicks` | integer | No | The total number of clicks to the campaign's URL. |
| `first_click` | string (date-time) | No | The timestamp for the first click to the URL. |
| `last_click` | string (date-time) | No | The timestamp for the last click to the URL. |
| `locations` | object[] | No | A summary of the top click locations. |

**`referrers` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|

| `first_click` | string (date-time) | No | The timestamp for the first click from this referrer. |
| `last_click` | string (date-time) | No | The timestamp for the last click from this referrer. |
