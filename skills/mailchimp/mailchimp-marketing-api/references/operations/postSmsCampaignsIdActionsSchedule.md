# POST /sms-campaigns/{sms_campaign_id}/actions/schedule

**Resource:** [sms-campaigns](../resources/sms-campaigns.md)
**Schedule SMS campaign**
**Operation ID:** `postSmsCampaignsIdActionsSchedule`

Schedule an SMS campaign to send at a specific time.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `sms_campaign_id` | path | string | Yes | The unique id for the SMS campaign. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

## Responses

| Status | Description |
|--------|-------------|
| 204 | Empty Response |
| default | An error generated by the Mailchimp API. |
