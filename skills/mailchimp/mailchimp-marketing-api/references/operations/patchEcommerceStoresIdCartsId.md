# PATCH /ecommerce/stores/{store_id}/carts/{cart_id}

**Resource:** [ecommerce](../resources/ecommerce.md)
**Update cart**
**Operation ID:** `patchEcommerceStoresIdCartsId`

Update a specific cart.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `store_id` | path | string | Yes | The store id. |
| `cart_id` | path | string | Yes | The id for the cart. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `customer` | object | No | Information about a specific customer. Orders for existing customers should include only the `id` parameter in the `customer` object body. |
| `campaign_id` | string | No | A string that uniquely identifies the campaign associated with a cart. |
| `checkout_url` | string | No | The URL for the cart. This parameter is required for [Abandoned Cart](https://mailchimp.com/help/create-an-abandoned-cart-email/) automations. |
| `currency_code` | string | No | The three-letter ISO 4217 code for the currency that the cart uses. |
| `order_total` | number | No | The order total for the cart. |
| `tax_total` | number | No | The total tax for the cart. |
| `lines` | object[] | No | An array of the cart's line items. |

**`customer` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `opt_in_status` | boolean | No | The customer's opt-in status. This value will never overwrite the opt-in status of a pre-existing Mailchimp list member, but will apply to list members that are added through the e-commerce API endpoints. Customers who don't opt in to your Mailchimp list [will be added as `Transactional` members](https://mailchimp.com/developer/marketing/docs/e-commerce/#customers). |
| `company` | string | No | The customer's company. |
| `first_name` | string | No | The customer's first name. |
| `last_name` | string | No | The customer's last name. |
| `address` | object | No | The customer's address. |

**`lines` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `product_id` | string | No | A unique identifier for the product associated with the cart line item. |
| `product_variant_id` | string | No | A unique identifier for the product variant associated with the cart line item. |
| `quantity` | integer | No | The quantity of a cart line item. |
| `price` | number | No | The price of a cart line item. |
