# POST /lists/{list_id}/segments

**Resource:** [lists](../resources/lists.md)
**Add segment**
**Operation ID:** `postListsIdSegments`

Create a new segment in a specific list.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | The name of the segment. |
| `static_segment` | string[] | No | An array of emails to be used for a static segment. Any emails provided that are not present on the list will be ignored. Passing an empty array will create a static segment without any subscribers. This field cannot be provided with the options field. |
| `options` | object | No | The [conditions of the segment](https://mailchimp.com/help/save-and-manage-segments/). Static and fuzzy segments don't have conditions. |

**`options` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `match` | enum: any, all | No | Match type. |
| `conditions` | any[] | No | Segment match conditions. There are multiple possible types, see the [condition types documentation](https://mailchimp.com/developer/marketing/docs/alternative-schemas/#segment-condition-schemas). |

| 200 |  |

| `name` | string | No | The name of the segment. |
| `member_count` | integer | No | The number of active subscribers currently included in the segment. |
| `type` | enum: saved, static, fuzzy | No | The type of segment. Static segments are now known as tags. Learn more about [tags](https://mailchimp.com/help/getting-started-tags?utm_source=mc-api&utm_medium=docs&utm_campaign=apidocs). |
| `created_at` | string (date-time) | No | The date and time the segment was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the segment was last updated in ISO 8601 format. |
| `options` | object | No | The conditions of the segment. Static segments (tags) and fuzzy segments don't have conditions. |
| `list_id` | string | No | The list id. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
