# GET /reports/{campaign_id}/email-activity/{subscriber_hash}

**Resource:** [reports](../resources/reports.md)
**Get subscriber email activity**
**Operation ID:** `getReportsIdEmailActivityId`

Get a specific list member's activity in a campaign including opens, clicks, and bounces.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `campaign_id` | path | string | Yes | The unique id for the campaign. |
| `subscriber_hash` | path | string | Yes | The MD5 hash of the lowercase version of the list member's email address. |
| `since` | query | string | No | Restrict results to email activity events that occur after a specific time. Uses ISO 8601 time format: 2015-10-21T15:41:36+00:00. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `campaign_id` | string | No | The unique id for the campaign. |
| `list_id` | string | No | The unique id for the list. |
| `list_is_active` | boolean | No | The status of the list used, namely if it's deleted or disabled. |
| `email_id` | string | No | The MD5 hash of the lowercase version of the list member's email address. |
| `email_address` | string | No | Email address for a subscriber. |
| `activity` | object[] | No | An array of objects, each showing an interaction with the email. Member activity limited to 1,000 open activities and 1,000 click activities per member per campaign. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`activity` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `action` | string | No | One of the following actions: 'open', 'click', or 'bounce' |
| `type` | string | No | If the action is a 'bounce', the type of bounce received: 'hard', 'soft'. |
| `timestamp` | string (date-time) | No | The date and time recorded for the action in ISO 8601 format. |
| `url` | string | No | If the action is a 'click', the URL on which the member clicked. |
| `ip` | string | No | The IP address recorded for the action. |
