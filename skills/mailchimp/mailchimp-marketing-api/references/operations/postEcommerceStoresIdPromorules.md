# POST /ecommerce/stores/{store_id}/promo-rules

**Resource:** [ecommerce](../resources/ecommerce.md)
**Add promo rule**
**Operation ID:** `postEcommerceStoresIdPromorules`

Add a new promo rule to a store.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `store_id` | path | string | Yes | The store id. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | A unique identifier for the promo rule. If Ecommerce platform does not support promo rule, use promo code id as promo rule id. Restricted to UTF-8 characters with max length 50. |
| `title` | string | No | The title that will show up in promotion campaign. Restricted to UTF-8 characters with max length of 100 bytes. |
| `description` | string | Yes | The description of a promotion restricted to UTF-8 characters with max length 255. |
| `starts_at` | string (date-time) | No | The date and time when the promotion is in effect in ISO 8601 format. |
| `ends_at` | string (Promo date-time) | No | The date and time when the promotion ends. Must be after starts_at and in ISO 8601 format. |
| `amount` | number (float) | Yes | The amount of the promo code discount. If 'type' is 'fixed', the amount is treated as a monetary value. If 'type' is 'percentage', amount must be a decimal value between 0.0 and 1.0, inclusive. |
| `type` | enum: fixed, percentage | Yes | Type of discount. For free shipping set type to fixed. |
| `target` | enum: per_item, total, shipping | Yes | The target that the discount applies to. |
| `enabled` | boolean | No | Whether the promo rule is currently enabled. |
| `created_at_foreign` | string (date-time) | No | The date and time the promotion was created in ISO 8601 format. |
| `updated_at_foreign` | string (date-time) | No | The date and time the promotion was updated in ISO 8601 format. |
