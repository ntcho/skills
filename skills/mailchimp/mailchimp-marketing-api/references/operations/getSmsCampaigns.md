# GET /sms-campaigns

**Resource:** [sms-campaigns](../resources/sms-campaigns.md)
**List SMS campaigns**
**Operation ID:** `getSmsCampaigns`

Get all SMS campaigns in an account.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |

**`sms_campaigns` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | A string that uniquely identifies this campaign. |
| `web_id` | string | No | The ID used in the Mailchimp web application. |
| `name` | string | No | The name of the campaign. |
| `status` | string | No | The current status of the campaign. |
| `channel` | string | No | The channel for this campaign (sms or whatsapp). |
| `list_id` | integer | No | The numeric ID of the list associated with this campaign. |
| `recipient_count` | integer | No | The number of recipients for this campaign. |
| `create_time` | string (date-time) | No | The date and time the campaign was created in ISO 8601 format. |
| `send_time` | string (date-time) | No | The date and time the campaign is scheduled to send. |
| `updated_at` | string (date-time) | No | The date and time the campaign was last updated. |
| `expire_time` | string (date-time) | No | The date and time the campaign will stop sending in ISO 8601 format. |
| `is_send_now` | boolean | No | Whether the campaign is configured to send immediately. |
| `folder_id` | string | No | The ID of the folder this campaign is in. |
| `segments` | integer[] | No | The segment IDs used to target recipients for this campaign. |
| `excluded_segments` | integer[] | No | The segment IDs excluded from receiving this campaign. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
