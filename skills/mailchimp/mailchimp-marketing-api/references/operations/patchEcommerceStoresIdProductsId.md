# PATCH /ecommerce/stores/{store_id}/products/{product_id}

**Resource:** [ecommerce](../resources/ecommerce.md)
**Update product**
**Operation ID:** `patchEcommerceStoresIdProductsId`

Update a specific product.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `store_id` | path | string | Yes | The store id. |
| `product_id` | path | string | Yes | The id for the product of a store. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | No | The title of a product. |
| `handle` | string | No | The handle of a product. |
| `url` | string | No | The URL for a product. |
| `description` | string | No | The description of a product. |
| `type` | string | No | The type of product. |
| `vendor` | string | No | The vendor for a product. |
| `image_url` | string | No | The image URL for a product. |
| `variants` | object[] | No | An array of the product's variants. At least one variant is required for each product. A variant can use the same `id` and `title` as the parent product. |
| `images` | object[] | No | An array of the product's images. |
| `published_at_foreign` | string (date-time) | No | The date and time the product was published in ISO 8601 format. |

**`variants` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | No | The title of a product variant. |
| `url` | string | No | The URL for a product variant. |
| `sku` | string | No | The stock keeping unit (SKU) of a product variant. |
| `price` | number | No | The price of a product variant. |
| `inventory_quantity` | integer | No | The inventory quantity of a product variant. |
| `image_url` | string | No | The image URL for a product variant. |
| `backorders` | string | No | The backorders of a product variant. |
| `visibility` | string | No | The visibility of a product variant. |

**`images` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | A unique identifier for the product image. |
| `url` | string | No | The URL for a product image. |
| `variant_ids` | any[] | No | The list of product variants using the image. |
