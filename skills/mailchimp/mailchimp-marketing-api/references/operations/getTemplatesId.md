# GET /templates/{template_id}

**Resource:** [templates](../resources/templates.md)
**Get template info**
**Operation ID:** `getTemplatesId`

Get information about a specific template.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `template_id` | path | string | Yes | The unique id for the template. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | integer | No | The individual id for the template. |
| `type` | string | No | The type of template (user, base, or gallery). |
| `name` | string | No | The name of the template. |
| `drag_and_drop` | boolean | No | Whether the template uses the drag and drop editor. |
| `responsive` | boolean | No | Whether the template contains media queries to make it responsive. |
| `category` | string | No | If available, the category the template is listed in. |
| `date_created` | string (date-time) | No | The date and time the template was created in ISO 8601 format. |
| `date_edited` | string (date-time) | No | The date and time the template was edited in ISO 8601 format. |
| `created_by` | string | No | The login name for template's creator. |
| `edited_by` | string | No | The login name who last edited the template. |
| `active` | boolean | No | User templates are not 'deleted,' but rather marked as 'inactive.' Returns whether the template is still active. |
| `folder_id` | string | No | The id of the folder the template is currently in. |
| `thumbnail` | string | No | If available, the URL for a thumbnail of the template. |
| `share_url` | string | No | The URL used for [template sharing](https://mailchimp.com/help/share-a-template/). |
| `content_type` | enum: template, multichannel, html | No | How the template's content is put together. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
