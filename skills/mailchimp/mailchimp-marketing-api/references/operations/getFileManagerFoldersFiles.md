# GET /file-manager/folders/{folder_id}/files

**Resource:** [fileManager](../resources/fileManager.md)
**List stored files**
**Operation ID:** `getFileManagerFoldersFiles`

Get a list of available images and files stored in this folder.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `folder_id` | path | string | Yes | The unique id for the File Manager folder. |
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |
| `type` | query | string | No | The file type for the File Manager file. |
| `created_by` | query | string | No | The Mailchimp account user who created the File Manager file. |
| `before_created_at` | query | string | No | Restrict the response to files created before the set date. Uses ISO 8601 time format: 2015-10-21T15:41:36+00:00. |
| `since_created_at` | query | string | No | Restrict the response to files created after the set date. Uses ISO 8601 time format: 2015-10-21T15:41:36+00:00. |
| `sort_field` | query | enum: added_date, name, size | No | Returns files sorted by the specified field. |
| `sort_dir` | query | enum: ASC, DESC | No | Determines the order direction for sorted results. |
