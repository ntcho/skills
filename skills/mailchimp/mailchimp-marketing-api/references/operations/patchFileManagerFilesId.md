# PATCH /file-manager/files/{file_id}

**Resource:** [fileManager](../resources/fileManager.md)
**Update file**
**Operation ID:** `patchFileManagerFilesId`

Update a file in the File Manager.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `file_id` | path | string | Yes | The unique id for the File Manager file. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `folder_id` | integer | No | The id of the folder. Setting `folder_id` to `0` will remove a file from its current folder. |
| `name` | string | No | The name of the file. |
