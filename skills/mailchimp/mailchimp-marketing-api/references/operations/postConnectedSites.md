# POST /connected-sites

**Resource:** [connectedSites](../resources/connectedSites.md)
**Add connected site**
**Operation ID:** `postConnectedSites`

Create a new Mailchimp connected site.

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `foreign_id` | string | Yes | The unique identifier for the site. |
| `domain` | string | Yes | The connected site domain. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `foreign_id` | string | No | The unique identifier for the site. |
| `store_id` | string | No | The unique identifier for the ecommerce store that's associated with the connected site (if any). The store_id for a specific connected site can't change. |
| `platform` | string | No | The platform of the connected site. |
| `domain` | string | No | The connected site domain. |
| `site_script` | object | No | The script used to connect your site with Mailchimp. |
| `is_pixel_enabled` | boolean | No | Whether the Mailchimp tracking pixel is enabled for this connected site. |
| `created_at` | string (date-time) | No | The date and time the connected site was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the connected site was last updated in ISO 8601 format. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`site_script` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `url` | string | No | The URL used for any integrations that offer built-in support for connected sites. |
| `fragment` | string | No | A pre-built script that you can copy-and-paste into your site to integrate it with Mailchimp. |

**`_links` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `rel` | string | No | As with an HTML 'rel' attribute, this describes the type of link. |
| `href` | string | No | This property contains a fully-qualified URL that can be called to retrieve the linked resource or perform the linked action. |
| `method` | enum: GET, POST, PUT... | No | The HTTP method that should be used when accessing the URL defined in 'href'. |
| `targetSchema` | string | No | For GETs, this is a URL representing the schema that the response should conform to. |
| `schema` | string | No | For HTTP methods that can receive bodies (POST and PUT), this is a URL representing the schema that the body should conform to. |
