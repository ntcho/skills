# GET /lists/{list_id}/interest-categories/{interest_category_id}

**Resource:** [lists](../resources/lists.md)
**Get interest category info**
**Operation ID:** `getListsIdInterestCategoriesId`

Get information about a specific interest category.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |
| `interest_category_id` | path | string | Yes | The unique ID for the interest category. |
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `list_id` | string | No | The unique list id for the category. |
| `id` | string | No | The id for the interest category. |
| `title` | string | No | The text description of this category. This field appears on signup forms and is often phrased as a question. |
| `display_order` | integer | No | The order that the categories are displayed in the list. Lower numbers display first. |
| `type` | enum: checkboxes, dropdown, radio... | No | Determines how this category’s interests appear on signup forms. |
