# POST /lists/{list_id}/members/{subscriber_hash}/tags

**Resource:** [lists](../resources/lists.md)
**Add or remove member tags**
**Operation ID:** `postListMemberTags`

Add or remove tags from a list member. If a tag that does not exist is passed in and set as 'active', a new tag will be created.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |
| `subscriber_hash` | path | string | Yes | The MD5 hash of the lowercase version of the list member's email address. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `tags` | object[] | Yes | A list of tags assigned to the list member. |
| `is_syncing` | boolean | No | When is_syncing is true, automations based on the tags in the request will not fire |

**`tags` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | The name of the tag. |
| `status` | enum: inactive, active | Yes | The status for the tag on the member, pass in active to add a tag or inactive to remove it. |

## Responses

| Status | Description |
|--------|-------------|
| 204 | Empty Response |
| default | An error generated by the Mailchimp API. |
