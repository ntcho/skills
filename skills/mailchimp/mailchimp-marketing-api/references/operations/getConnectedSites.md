# GET /connected-sites

**Resource:** [connectedSites](../resources/connectedSites.md)
**List connected sites**
**Operation ID:** `getConnectedSites`

Get all connected sites in an account.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `sites` | object[] | No | An array of objects, each representing a connected site. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`sites` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `foreign_id` | string | No | The unique identifier for the site. |
| `store_id` | string | No | The unique identifier for the ecommerce store that's associated with the connected site (if any). The store_id for a specific connected site can't change. |
| `platform` | string | No | The platform of the connected site. |
| `domain` | string | No | The connected site domain. |
| `site_script` | object | No | The script used to connect your site with Mailchimp. |
| `is_pixel_enabled` | boolean | No | Whether the Mailchimp tracking pixel is enabled for this connected site. |
| `created_at` | string (date-time) | No | The date and time the connected site was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the connected site was last updated in ISO 8601 format. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
