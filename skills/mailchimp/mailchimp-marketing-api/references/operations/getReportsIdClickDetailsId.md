# GET /reports/{campaign_id}/click-details/{link_id}

**Resource:** [reports](../resources/reports.md)
**Get campaign link details**
**Operation ID:** `getReportsIdClickDetailsId`

Get click details for a specific link in a campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `campaign_id` | path | string | Yes | The unique id for the campaign. |
| `link_id` | path | string | Yes | The id for the link. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | The unique id for the link. |
| `url` | string | No | The URL for the link in the campaign. |
| `total_clicks` | integer | No | The number of total clicks for a link. |
| `click_percentage` | number | No | The percentage of total clicks a link generated for a campaign. |
| `unique_clicks` | integer | No | Number of unique clicks for a link. |
| `unique_click_percentage` | number | No | The percentage of unique clicks a link generated for a campaign. |
| `last_click` | string (date-time) | No | The date and time for the last recorded click for a link in ISO 8601 format. |
| `ab_split` | object | No | A breakdown of clicks by different groups of an A/B Split campaign. Does not return information about Multivariate Campaigns. |
| `campaign_id` | string | No | The campaign id. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`ab_split` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `a` | object | No | Stats for Group A. |
| `b` | object | No | Stats for Group B. |
