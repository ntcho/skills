# GET /ecommerce/stores/{store_id}/carts

**Resource:** [ecommerce](../resources/ecommerce.md)
**List carts**
**Operation ID:** `getEcommerceStoresIdCarts`

Get information about a store's carts.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |
| `store_id` | path | string | Yes | The store id. |

| `campaign_id` | string | No | A string that uniquely identifies the campaign associated with a cart. |
| `checkout_url` | string | No | The URL for the cart. This parameter is required for [Abandoned Cart](https://mailchimp.com/help/create-an-abandoned-cart-email/) automations. |

| `order_total` | number | No | The order total for the cart. |
| `tax_total` | number | No | The total tax for the cart. |
| `lines` | object[] | No | An array of the cart's line items. |
| `created_at` | string (date-time) | No | The date and time the cart was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the cart was last updated in ISO 8601 format. |
