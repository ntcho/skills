# GET /ecommerce/stores

**Resource:** [ecommerce](../resources/ecommerce.md)
**List stores**
**Operation ID:** `getEcommerceStores`

Get information about all stores in the account.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `stores` | object[] | No | An array of objects, each representing a store. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`stores` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | The unique identifier for the store. |
| `list_id` | string | No | The unique identifier for the list that's associated with the store. The `list_id` for a specific store can't change. |
| `name` | string | No | The name of the store. |
| `platform` | string | No | The e-commerce platform of the store. |
| `domain` | string | No | The store domain.  The store domain must be unique within a user account. |
| `is_syncing` | boolean | No | Whether to disable automations because the store is currently [syncing](https://mailchimp.com/developer/marketing/docs/e-commerce/#pausing-store-automations). |
| `email_address` | string | No | The email address for the store. |
| `currency_code` | string | No | The three-letter ISO 4217 code for the currency that the store accepts. |
| `money_format` | string | No | The currency format for the store. For example: `$`, `£`, etc. |
| `primary_locale` | string | No | The primary locale for the store. For example: `en`, `de`, etc. |
| `timezone` | string | No | The timezone for the store. |
| `phone` | string | No | The store phone number. |
| `address` | object | No | The store address. |
| `connected_site` | object | No | The Connected Site associated with the store. |
| `automations` | object | No | Details for the automations attached to this store. |
| `list_is_active` | boolean | No | The status of the list connected to the store, namely if it's deleted or disabled. |
| `created_at` | string (date-time) | No | The date and time the store was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the store was last updated in ISO 8601 format. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
