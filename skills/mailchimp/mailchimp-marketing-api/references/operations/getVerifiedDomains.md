# GET /verified-domains

**Resource:** [verifiedDomains](../resources/verifiedDomains.md)
**List sending domains**
**Operation ID:** `getVerifiedDomains`

Get all of the sending domains on the account.

## Responses

| Status | Description |
|--------|-------------|
| 200 | The domains on the account. |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `domains` | object[] | No | The domains on the account |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |

**`domains` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `domain` | string | No | The name of this domain. |
| `verified` | boolean | No | Whether the domain has been verified for sending. |
| `authenticated` | boolean | No | Whether domain authentication is enabled for this domain. |
| `verification_email` | string | No | The e-mail address receiving the two-factor challenge for this domain. |
| `verification_sent` | string (date-time) | No | The date/time that the two-factor challenge was sent to the verification email. |
| `status` | enum: VERIFICATION_IN_PROGRESS, VERIFIED, EXPIRED... | No | The Domain's current status. |
| `is_free_email_provider` | boolean | No | Returns whether the domain used is a public / free email provider. See [Limitations of Free Email Addresses](https://mailchimp.com/help/limitations-of-free-email-addresses/) for more details. |
