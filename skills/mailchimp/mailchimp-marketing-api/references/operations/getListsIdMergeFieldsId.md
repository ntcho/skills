# GET /lists/{list_id}/merge-fields/{merge_id}

**Resource:** [lists](../resources/lists.md)
**Get merge field**
**Operation ID:** `getListsIdMergeFieldsId`

Get information about a specific merge field.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |
| `merge_id` | path | string | Yes | The id for the merge field. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `merge_id` | integer | No | An unchanging id for the merge field. |
| `tag` | string | No | The merge tag used for Mailchimp campaigns and [adding contact information](https://mailchimp.com/developer/marketing/docs/merge-fields/#add-merge-data-to-contacts). |
| `name` | string | No | The name of the merge field (audience field). |
| `type` | enum: text, number, address... | No | The [type](https://mailchimp.com/developer/marketing/docs/merge-fields/#structure) for the merge field. |
| `required` | boolean | No | The boolean value if the merge field is required. |
| `default_value` | string | No | The default value for the merge field if `null`. |
| `public` | boolean | No | Whether the merge field is displayed on the signup form. |
| `display_order` | integer | No | The order that the merge field displays on the list signup form. |
| `options` | object | No | Extra options for some merge field types. |
| `help_text` | string | No | Extra text to help the subscriber fill out the form. |
| `list_id` | string | No | The ID that identifies this merge field's audience'. |
| `total_items` | integer | No | The total number of merge fields on the audience after this field was created. Returned on POST responses only. |
| `merge_field_limit` | integer | No | The maximum number of merge fields this audience can hold. The limit is determined by the account's plan. Returned on POST responses only. Subtract `total_items` from this value to derive the remaining capacity. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
