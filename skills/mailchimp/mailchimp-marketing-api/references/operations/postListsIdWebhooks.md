# POST /lists/{list_id}/webhooks

**Resource:** [lists](../resources/lists.md)
**Add webhook**
**Operation ID:** `postListsIdWebhooks`

Create a new webhook for a specific list.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | An string that uniquely identifies this webhook. |
| `url` | string | No | A valid URL for the Webhook. |
| `events` | object | No | The events that can trigger the webhook and whether they are enabled. |
| `sources` | object | No | The possible sources of any events that can trigger the webhook and whether they are enabled. |
| `list_id` | string | No | The unique id for the list. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`events` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `subscribe` | boolean | No | Whether the webhook is triggered when a list subscriber is added. |
| `unsubscribe` | boolean | No | Whether the webhook is triggered when a list member unsubscribes. |
| `profile` | boolean | No | Whether the webhook is triggered when a contact's profile is updated. This includes email subscribers and SMS-only contacts [BETA]. |
| `cleaned` | boolean | No | Whether the webhook is triggered when a subscriber's email address is cleaned from the list. |
| `upemail` | boolean | No | Whether the webhook is triggered when a subscriber's email address is changed. |
| `campaign` | boolean | No | Whether the webhook is triggered when a campaign is sent or cancelled. |
| `sms_subscribe` | boolean | No | [BETA] Whether the webhook is triggered when a contact subscribes to SMS. |
| `sms_unsubscribe` | boolean | No | [BETA] Whether the webhook is triggered when a contact unsubscribes from SMS. |
| `upsms` | boolean | No | [BETA] Whether the webhook is triggered when a contact's SMS phone number is updated. |
| `sms_campaign` | boolean | No | [BETA] Whether the webhook is triggered when an SMS campaign is sent. |

**`sources` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `user` | boolean | No | Whether the webhook is triggered by subscriber-initiated actions. |
| `admin` | boolean | No | Whether the webhook is triggered by admin-initiated actions in the web interface. |
| `api` | boolean | No | Whether the webhook is triggered by actions initiated via the API. |

**`_links` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `rel` | string | No | As with an HTML 'rel' attribute, this describes the type of link. |
| `href` | string | No | This property contains a fully-qualified URL that can be called to retrieve the linked resource or perform the linked action. |
| `method` | enum: GET, POST, PUT... | No | The HTTP method that should be used when accessing the URL defined in 'href'. |
| `targetSchema` | string | No | For GETs, this is a URL representing the schema that the response should conform to. |
| `schema` | string | No | For HTTP methods that can receive bodies (POST and PUT), this is a URL representing the schema that the body should conform to. |
