# PUT /campaigns/{campaign_id}/content

**Resource:** [campaigns](../resources/campaigns.md)
**Set campaign content**
**Operation ID:** `putCampaignsIdContent`

Set the content for a campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `campaign_id` | path | string | Yes | The unique id for the campaign. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `plain_text` | string | No | The plain-text portion of the campaign. If left unspecified, we'll generate this automatically. |
| `html` | string | No | The raw HTML for the campaign. |
| `url` | string | No | When importing a campaign, the URL where the HTML lives. |
| `template` | object | No | Use this template to generate the HTML content of the campaign |
| `archive` | object | No | Available when uploading an archive to create campaign content. The archive should include all campaign content and images. [Learn more](https://mailchimp.com/help/import-a-custom-html-template/). |
| `variate_contents` | object[] | No | Content options for [Multivariate Campaigns](https://mailchimp.com/help/about-multivariate-campaigns/). Each content option must provide HTML content and may optionally provide plain text. For campaigns not testing content, only one object should be provided. |

**`template` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | integer | Yes | The id of the template to use. |
| `sections` | object | No | Content for the sections of the template. Each key should be the unique [mc:edit area](https://mailchimp.com/help/create-editable-content-areas-with-mailchimps-template-language/) name from the template. |

**`archive` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `archive_content` | string | Yes | The base64-encoded representation of the archive file. |
| `archive_type` | enum: zip, tar.gz, tar.bz2... | No | The type of encoded file. Defaults to zip. |

**`variate_contents` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content_label` | string | Yes | The label used to identify the content option. |
| `plain_text` | string | No | The plain-text portion of the campaign. If left unspecified, we'll generate this automatically. |
| `html` | string | No | The raw HTML for the campaign. |
| `url` | string | No | When importing a campaign, the URL for the HTML. |
| `template` | object | No | Use this template to generate the HTML content for the campaign. |
| `archive` | object | No | Available when uploading an archive to create campaign content. The archive should include all campaign content and images. [Learn more](https://mailchimp.com/help/import-a-custom-html-template/). |
