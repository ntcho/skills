# GET /reporting/surveys/{survey_id}

**Resource:** [reporting](../resources/reporting.md)
**Get survey report**
**Operation ID:** `getReportingSurveysId`

Get report for a survey.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `survey_id` | path | string | Yes | The ID of the survey. |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Survey Report Instance |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | A string that uniquely identifies this survey. |
| `web_id` | integer | No | The ID used in the Mailchimp web application. View this survey report in your Mailchimp account at `https://{dc}.admin.mailchimp.com/lists/surveys/results?survey_id={web_id}`. |
| `list_id` | string | No | The ID of the list connected to this survey. |
| `list_name` | string | No | The name of the list connected to this survey. |
| `title` | string | No | The title of the survey. |
| `url` | string | No | The URL for the survey. |
| `status` | enum: published, unpublished | No | The survey's status. |
| `published_at` | string (date-time) | No | The date and time the survey was published in ISO 8601 format. |
| `created_at` | string (date-time) | No | The date and time the survey was created in ISO 8601 format. |
| `updated_at` | string (date-time) | No | The date and time the survey was last updated in ISO 8601 format. |
| `total_responses` | integer | No | The total number of responses to this survey. |
