# POST /account-exports

**Resource:** [accountExports](../resources/accountExports.md)
**Add export**
**Operation ID:** `postAccountExport`

Create a new account export in your Mailchimp account.

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `include_stages` | string[] | Yes | The stages of an account export to include. |
| `since_timestamp` | string (date-time) | No | An ISO 8601 date that will limit the export to only records created after a given time. For instance, the reports stage will contain any campaign sent after the given timestamp. Audiences, however, are excluded from this limit. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `export_id` | integer | No | The ID for the export. |
| `started` | string (date-time) | No | Start time for the export. |
| `finished` | string (date-time) | No | If finished, the finish time for the export. |
| `size_in_bytes` | integer | No | The size of the uncompressed export in bytes. |
| `download_url` | string | No | If the export is finished, the download URL for an export. URLs are only valid for 90 days after the export completes. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`_links` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `rel` | string | No | As with an HTML 'rel' attribute, this describes the type of link. |
| `href` | string | No | This property contains a fully-qualified URL that can be called to retrieve the linked resource or perform the linked action. |
| `method` | enum: GET, POST, PUT... | No | The HTTP method that should be used when accessing the URL defined in 'href'. |
| `targetSchema` | string | No | For GETs, this is a URL representing the schema that the response should conform to. |
| `schema` | string | No | For HTTP methods that can receive bodies (POST and PUT), this is a URL representing the schema that the body should conform to. |
