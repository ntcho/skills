# PUT /ecommerce/stores/{store_id}/products/{product_id}/variants/{variant_id}

**Resource:** [ecommerce](../resources/ecommerce.md)
**Add or update product variant**
**Operation ID:** `putEcommerceStoresIdProductsIdVariantsId`

Add or update a product variant.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `store_id` | path | string | Yes | The store id. |
| `product_id` | path | string | Yes | The id for the product of a store. |
| `variant_id` | path | string | Yes | The id for the product variant. |
