# POST /lists/{list_id}/segments/{segment_id}

**Resource:** [lists](../resources/lists.md)
**Batch add or remove members**
**Operation ID:** `postListsIdSegmentsId`

Batch add/remove list members to static segment

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `list_id` | path | string | Yes | The unique ID for the list. |
| `segment_id` | path | string | Yes | The unique id for the segment. |

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `members_to_add` | string[] | No | An array of emails to be used for a static segment. Any emails provided that are not present on the list will be ignored. A maximum of 500 members can be sent. |
| `members_to_remove` | string[] | No | An array of emails to be used for a static segment. Any emails provided that are not present on the list will be ignored. A maximum of 500 members can be sent. |

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

| `errors` | object[] | No | An array of objects, each representing an array of email addresses that could not be added to the segment or removed and an error message providing more details. |
