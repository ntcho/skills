# GET /reporting/surveys/{survey_id}/questions/{question_id}

**Resource:** [reporting](../resources/reporting.md)
**Get survey question report**
**Operation ID:** `getReportingSurveysIdQuestionsId`

Get report for a survey question.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `survey_id` | path | string | Yes | The ID of the survey. |
| `question_id` | path | string | Yes | The ID of the survey question. |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Survey Question Report Instance |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | The ID of the survey question. |
| `survey_id` | string | No | The unique ID of the survey. |
| `query` | string | No | The query of the survey question. |
| `type` | enum: pickOne, pickMany, range... | No | The response type of the survey question. |
| `total_responses` | integer | No | The total number of responses to this question. |
| `is_required` | boolean | No | Whether this survey question is required to answer. |
| `has_other` | boolean | No | Whether this survey question has an 'other' option. |
| `other_label` | string | No | Label used for the 'other' option of this survey question. |
| `average_rating` | number (float) | No | The average rating for this range question. |
| `range_low_label` | string | No | Label for the low end of the range. |
| `range_high_label` | string | No | Label for the high end of the range. |
| `placeholder_label` | string | No | Placeholder text for this survey question's answer box. |
| `subscribe_checkbox_enabled` | boolean | No | Whether the subscribe checkbox is shown for this email question. |
| `subscribe_checkbox_label` | string | No | Label used for the subscribe checkbox for this email question. |
| `merge_field` | object | No | A [merge field](https://mailchimp.com/developer/marketing/docs/merge-fields/) for an audience. |
| `options` | object[] | No | The answer choices for this question. |
| `contact_counts` | object | No | For email question types, how many are new, known, or unknown contacts. |

**`merge_field` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | integer | No | An unchanging id for the merge field. |
| `label` | string | No | The [label](https://mailchimp.com/developer/marketing/docs/merge-fields/#structure) for the merge field. |
| `type` | enum: text, number, address... | No | The [type](https://mailchimp.com/developer/marketing/docs/merge-fields/#structure) for the merge field. |

**`options` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `label` | string | No | The label for this survey question option. |
| `id` | string | No | The ID for this survey question option. |
| `count` | integer | No | The count of responses that selected this survey question option. |

**`contact_counts` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `known` | integer | No | The number of known contacts that responded to this survey. |
| `unknown` | integer | No | The number of unknown contacts that responded to this survey. |
| `new` | integer | No | The number of new contacts that responded to this survey. |
