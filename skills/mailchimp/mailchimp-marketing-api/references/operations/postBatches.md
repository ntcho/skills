# POST /batches

**Resource:** [batches](../resources/batches.md)
**Start batch operation**
**Operation ID:** `postBatches`

Begin processing a batch operations request.

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `operations` | object[] | Yes | An array of objects that describes operations to perform. |

**`operations` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `method` | enum: GET, POST, PUT... | Yes | The HTTP method to use for the operation. |
| `headers` | object | No | Any HTTP headers to include with the request. |
| `path` | string | Yes | The relative path to use for the operation. |
| `params` | object | No | Any request query parameters. Example parameters: {"count":10, "offset":0} |
| `body` | string | No | A string containing the JSON body to use with the request. |
| `operation_id` | string | No | An optional client-supplied id returned with the operation results. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | A string that uniquely identifies this batch request. |
| `status` | enum: pending, preprocessing, started... | No | The status of the batch call. [Learn more](https://mailchimp.com/developer/marketing/guides/run-async-requests-batch-endpoint/#check-the-status-of-a-batch-operation) about the batch operation status. |
| `total_operations` | integer | No | The total number of operations to complete as part of this batch request. For GET requests requiring pagination, each page counts as a separate operation. |
| `finished_operations` | integer | No | The number of completed operations. This includes operations that returned an error. |
| `errored_operations` | integer | No | The number of completed operations that returned an error. |
| `submitted_at` | string (date-time) | No | The date and time when the server received the batch request in ISO 8601 format. |
| `completed_at` | string (date-time) | No | The date and time when all operations in the batch request completed in ISO 8601 format. |
| `response_body_url` | string | No | The URL of the gzipped archive of the results of all the operations. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`_links` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `rel` | string | No | As with an HTML 'rel' attribute, this describes the type of link. |
| `href` | string | No | This property contains a fully-qualified URL that can be called to retrieve the linked resource or perform the linked action. |
| `method` | enum: GET, POST, PUT... | No | The HTTP method that should be used when accessing the URL defined in 'href'. |
| `targetSchema` | string | No | For GETs, this is a URL representing the schema that the response should conform to. |
| `schema` | string | No | For HTTP methods that can receive bodies (POST and PUT), this is a URL representing the schema that the body should conform to. |
