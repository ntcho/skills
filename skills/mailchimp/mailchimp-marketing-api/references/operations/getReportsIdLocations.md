# GET /reports/{campaign_id}/locations

**Resource:** [reports](../resources/reports.md)
**List top open activities**
**Operation ID:** `getReportsIdLocations`

Get top open locations for a specific campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `campaign_id` | path | string | Yes | The unique id for the campaign. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |
| `offset` | query | integer | No | Used for [pagination](https://mailchimp.com/developer/marketing/docs/methods-parameters/#pagination), this is the number of records from a collection to skip. Default value is 0. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `locations` | object[] | No | An array of objects, each representing a top location for opens. |
| `campaign_id` | string | No | The campaign id. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`locations` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `country_code` | string | No | The ISO 3166 2 digit country code. |
| `region` | string | No | An internal code for the region representing the more specific location area such as city or state. When this is blank, it indicates we know the country, but not the region. |
| `region_name` | string | No | The name of the region, if we have one. For blank "region" values, this will be "Rest of Country". |
| `opens` | integer | No | The number of unique campaign opens for a region. |
| `proxy_excluded_opens` | integer | No | The number of unique campaign opens for a region excluding opens from email clients that use proxies. |
