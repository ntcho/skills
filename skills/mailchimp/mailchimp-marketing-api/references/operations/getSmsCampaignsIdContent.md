# GET /sms-campaigns/{sms_campaign_id}/content

**Resource:** [sms-campaigns](../resources/sms-campaigns.md)
**Get SMS campaign content**
**Operation ID:** `getSmsCampaignsIdContent`

Get the content for an SMS campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `sms_campaign_id` | path | string | Yes | The unique id for the SMS campaign. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `message_body` | string | No | The SMS message body. |
| `estimated_segments` | integer | No | The estimated number of message segments this content will use. |
| `merge_fields` | string[] | No | The merge fields used in the message body. |
| `media` | object[] | No | Attached images or files. |
| `source` | object | No | The source that created or imported this content. |
