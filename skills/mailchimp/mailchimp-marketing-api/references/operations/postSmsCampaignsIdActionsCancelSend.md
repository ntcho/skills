# POST /sms-campaigns/{sms_campaign_id}/actions/cancel-send

**Resource:** [sms-campaigns](../resources/sms-campaigns.md)
**Cancel SMS campaign send**
**Operation ID:** `postSmsCampaignsIdActionsCancelSend`

Cancel a scheduled or sending SMS campaign.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `sms_campaign_id` | path | string | Yes | The unique id for the SMS campaign. |

## Responses

| Status | Description |
|--------|-------------|
| 204 | Empty Response |
| default | An error generated by the Mailchimp API. |
