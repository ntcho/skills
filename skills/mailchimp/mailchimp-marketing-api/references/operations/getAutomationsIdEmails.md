# GET /automations/{workflow_id}/emails

**Resource:** [automations](../resources/automations.md)
**List automated emails**
**Operation ID:** `getAutomationsIdEmails`

Get a summary of the emails in a classic automation workflow.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `workflow_id` | path | string | Yes | The unique id for the Automation workflow. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `emails` | object[] | No | An array of objects, each representing an email in an Automation workflow. |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |
