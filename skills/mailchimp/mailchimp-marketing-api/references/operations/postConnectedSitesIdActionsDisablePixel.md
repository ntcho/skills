# POST /connected-sites/{connected_site_id}/actions/disable-pixel

**Resource:** [connectedSites](../resources/connectedSites.md)
**Disable pixel for connected site**
**Operation ID:** `postConnectedSitesIdActionsDisablePixel`

Disable the Mailchimp tracking pixel for a connected site.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `connected_site_id` | path | string | Yes | The unique identifier for the site. |

## Responses

| Status | Description |
|--------|-------------|
| 204 | Empty Response |
| default | An error generated by the Mailchimp API. |
