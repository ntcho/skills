# GET /landing-pages

**Resource:** [landingPages](../resources/landingPages.md)
**List landing pages**
**Operation ID:** `getAllLandingPages`

Get all landing pages.

## Parameters

| Name | In | Type | Required | Description |
|------|------|------|----------|-------------|
| `sort_dir` | query | enum: ASC, DESC | No | Determines the order direction for sorted results. |
| `sort_field` | query | enum: created_at, updated_at | No | Returns files sorted by the specified field. |
| `fields` | query | string[] | No | A comma-separated list of fields to return. Reference parameters of sub-objects with dot notation. |
| `exclude_fields` | query | string[] | No | A comma-separated list of fields to exclude. Reference parameters of sub-objects with dot notation. |
| `count` | query | integer | No | The number of records to return. Default value is 10. Maximum value is 1000 |

## Responses

| Status | Description |
|--------|-------------|
| 200 | Landing Pages Collection |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `landing_pages` | object[] | No | The landing pages on the account |
| `total_items` | integer | No | The total number of items matching the query regardless of pagination. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

| Field | Type | Required | Description |

| `description` | string | No | The description of this landing page. |
| `template_id` | integer | No | The template_id of this landing page. |
| `status` | enum: published, unpublished, draft | No | The status of this landing page. |
| `list_id` | string | No | The list's ID associated with this landing page. |
| `store_id` | string | No | The ID of the store associated with this landing page. |
| `web_id` | integer | No | The ID used in the Mailchimp web application. |
| `created_by_source` | string | No | Created by mobile or web |
| `url` | string | No | The url of the published landing page. |
| `created_at` | string (date-time) | No | The time this landing page was created. |
| `published_at` | string (date-time) | No | The time this landing page was published. |
| `unpublished_at` | string (date-time) | No | The time this landing page was unpublished. |
| `updated_at` | string (date-time) | No | The time this landing page was updated at. |
