# POST /automations

**Resource:** [automations](../resources/automations.md)
**Add automation**
**Operation ID:** `postAutomations`

Create a new classic automation in your Mailchimp account.

## Request Body

**Required:** Yes

**Content Types:** `application/json`

**Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `recipients` | object | Yes | List settings for the Automation. |
| `settings` | object | No | The settings for the Automation workflow. |
| `trigger_settings` | object | Yes | Trigger settings for the Automation. |

**`recipients` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `list_id` | string | No | The id of the List. |
| `store_id` | string | No | The id of the store. |

**`settings` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `from_name` | string | No | The 'from' name for the Automation (not an email address). |
| `reply_to` | string | No | The reply-to email address for the Automation. |

**`trigger_settings` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `workflow_type` | string | Yes | The type of Automation workflow. Currently only supports 'abandonedCart'. |

## Responses

| Status | Description |
|--------|-------------|
| 200 |  |
| default | An error generated by the Mailchimp API. |

**Success Response Schema** (inline):

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | No | A string that identifies the Automation. |
| `create_time` | string (date-time) | No | The date and time the Automation was created in ISO 8601 format. |
| `start_time` | string (date-time) | No | The date and time the Automation was started in ISO 8601 format. |
| `status` | enum: save, paused, sending | No | The current status of the Automation. |
| `emails_sent` | integer | No | The total number of emails sent for the Automation. |
| `recipients` | object | No | List settings for the Automation. |
| `settings` | object | No | The settings for the Automation workflow. |
| `tracking` | object | No | The tracking options for the Automation. |
| `trigger_settings` | object | No | Available triggers for Automation workflows. |
| `report_summary` | object | No | A summary of opens and clicks for sent campaigns. |
| `_links` | object[] | No | A list of link types and descriptions for the API schema documents. |

**`recipients` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `list_id` | string | No | The unique list id. |
| `list_is_active` | boolean | No | The status of the list used, namely if it's deleted or disabled. |
| `list_name` | string | No | List Name. |
| `segment_opts` | object | No | An object representing all segmentation options. |
| `store_id` | string | No | The id of the store. |

**`settings` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | No | The title of the Automation. |
| `from_name` | string | No | The 'from' name for the Automation (not an email address). |
| `reply_to` | string | No | The reply-to email address for the Automation. |
| `use_conversation` | boolean | No | Whether to use Mailchimp Conversation feature to manage replies |
| `to_name` | string | No | The Automation's custom 'To' name, typically the first name [audience field](https://mailchimp.com/help/getting-started-with-merge-tags/). |
| `authenticate` | boolean | No | Whether Mailchimp [authenticated](https://mailchimp.com/help/about-email-authentication/) the Automation. Defaults to `true`. |
| `auto_footer` | boolean | No | Whether to automatically append Mailchimp's [default footer](https://mailchimp.com/help/about-campaign-footers/) to the Automation. |
| `inline_css` | boolean | No | Whether to automatically inline the CSS included with the Automation content. |

**`tracking` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `opens` | boolean | No | Whether to [track opens](https://mailchimp.com/help/about-open-tracking/). Defaults to `true`. |
| `html_clicks` | boolean | No | Whether to [track clicks](https://mailchimp.com/help/enable-and-view-click-tracking/) in the HTML version of the Automation. Defaults to `true`. |
| `text_clicks` | boolean | No | Whether to [track clicks](https://mailchimp.com/help/enable-and-view-click-tracking/) in the plain-text version of the Automation. Defaults to `true`. |
| `goal_tracking` | boolean | No | Deprecated |
| `ecomm360` | boolean | No | Whether to enable e-commerce tracking. |
| `google_analytics` | string | No | The custom slug for [Google Analytics](https://mailchimp.com/help/integrate-google-analytics-with-mailchimp/) tracking (max of 50 bytes). |
| `clicktale` | string | No | The custom slug for [ClickTale](https://mailchimp.com/help/additional-tracking-options-for-campaigns/) tracking (max of 50 bytes). |
| `salesforce` | object | No | Deprecated |
| `capsule` | object | No | Deprecated |

**`trigger_settings` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `workflow_type` | enum: abandonedBrowse, abandonedCart, api... | Yes | The type of Automation workflow. |
| `workflow_title` | string | No | The title of the workflow type. |
| `runtime` | object | No | A workflow's runtime settings for an Automation. |
| `workflow_emails_count` | integer | No | The number of emails in the Automation workflow. |

**`report_summary` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `opens` | integer | No | The total number of opens for a campaign. |
| `unique_opens` | integer | No | The number of unique opens. |
| `open_rate` | number | No | The number of unique opens divided by the total number of successful deliveries. |
| `clicks` | integer | No | The total number of clicks for an campaign. |
| `subscriber_clicks` | integer | No | The number of unique clicks. |
| `click_rate` | number | No | The number of unique clicks, divided by the total number of successful deliveries. |

**`_links` fields:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `rel` | string | No | As with an HTML 'rel' attribute, this describes the type of link. |
| `href` | string | No | This property contains a fully-qualified URL that can be called to retrieve the linked resource or perform the linked action. |
| `method` | enum: GET, POST, PUT... | No | The HTTP method that should be used when accessing the URL defined in 'href'. |
| `targetSchema` | string | No | For GETs, this is a URL representing the schema that the response should conform to. |
| `schema` | string | No | For HTTP methods that can receive bodies (POST and PUT), this is a URL representing the schema that the body should conform to. |
